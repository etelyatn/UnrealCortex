## Intent and acceptance

Migration-wave planning must be possible from a few calls: who references an asset (including config), what is broken in config, a typed project dependency graph with a wave order, and a one-call analysis export.

| Criterion | Current evidence | Route | Minimal proof and exit |

| `reflect.find_broken_config_paths` reports missing package/directory paths | none | Implement | Native test: temp ini with an existing and a missing path; Ripper toxicity penalty paths live |

## Decisions

### D1 Config scanner (shared by D1/D2/D4)
Private CortexReflect helper `CortexReflectConfigScan::Scan() -> TArray<FConfigReference>` with `{File (project-relative), Line, Section, Key, Value, Path}`. Files: `FPaths::ProjectConfigDir()/*.ini` (non-recursive, excludes `Saved/`), and `Config/*.ini` of every enabled plugin whose base dir is under `FPaths::ProjectDir()` (project plugins, not engine plugins). Raw line scan (keeps line numbers): track `[Section]`, skip `;`/`#` comments, split `Key=Value` (strip `+ - . !` prefixes). Extract every token matching a long package path whose first segment is a registered content root (`FPackageName::QueryRootContentPaths`, `/Script/` excluded): a path token: every character valid in an object path (`FPackageName` long package names plus `.`, including `+` and `-`; `INVALID_OBJECTPATH_CHARACTERS` plus `:`, `\`, `<`, `>` terminate it), trimmed of trailing dots. A token containing `*` or `?` is a wildcard pattern and is skipped. In `*Redirects` keys and the `[CoreRedirects]` section the `Old*` attributes (OldName, OldClassName, ...) name packages that intentionally no longer exist and are skipped; `NewName` targets are still references. Normalise to package name (`ObjectPathToPackageName`, strip trailing `_C`/subobject). Directory-like tokens (trailing `/`, or no package and no `.` in the leaf) are tagged `kind:"directory"`.

`get_referencers` appends rows `{package:<ini file>, type:"config", file, line, section, key}` for tokens whose package equals the queried package; `total`/`total_unfiltered` include them; new optional `include_config:bool=true`. `limit` counts all rows; config rows are listed before asset rows so a small `limit` keeps them.

`reflect.find_broken_config_paths {}` → `{scanned_files, unreadable_files:[file], checked, broken:[{file,line,section,key,value,path,kind}]}`; `scanned_files` counts the INI files actually read and an unreadable file is listed instead of being silently dropped. The command is `StrictParams` (accepts no parameters). A package token is broken if neither `FindPackage` nor `FPackageName::DoesPackageExist`; a directory token is broken if neither Asset Registry `PathExists` nor the mapped disk directory exists.

### D2 blueprint.export_migration_analysis
Params: `paths:array[string]` or `path_prefix:string` (exactly one), `types:array[string]` (blueprint.list vocabulary), `sections:array[string]` (analyze vocabulary plus `graph_metrics`), `out_path:string` (required; existing export convention `out_path`, not `output_path`; resolved by `FCortexSafeFileContract::ResolveWritePath`, i.e. under Saved/Content/Config). Writes JSONL (one `{asset_path, analysis, graph_metrics?}` per line, error rows `{asset_path, error_code, error_message}`) atomically, and `<out_path minus extension>.index.json` with rows `{name, asset_path, type, parent_class, native_parent_class, parent_chain:[BP ancestors], metrics:{functional_nodes, has_tick, unreachable_nodes, conditionals}, violations, migration_confidence, unsupported_node_types, blockers:[...]}`. Implementation reuses the analyze builder and graph_metrics builder in-process (no TCP calls). Read-only for assets; writes only the export files.

`path_prefix` requests report `totals.matched_assets` (Blueprints found under the folder before the `types` filter) and a `warnings` entry when the folder matched none; index violations always use the default `graph_metrics` thresholds (10 nodes per entry, 30 per Blueprint) because the command has no `thresholds` parameter. Enumeration and request validation mirror `blueprint.compile_all` (CortexBPCompileAllOps.cpp): exactly one of `path_prefix`/`paths`, mounted-folder validation, Asset Registry enumeration without loading, level-script Blueprints excluded, `types` validated against `FCortexBPAssetOps::GetBlueprintTypeNames()` (case-insensitive), missing paths reported as rows, assets blocked by the mutation guard skipped with a reason. Sections default to all of `GetMigrationSectionNames()` plus `graph_metrics`; unknown names refused before any load. Each Blueprint goes through the same in-process builders as `analyze_for_migration` and `graph_metrics` (shared functions, not copies); garbage is collected once at the end. Index written with `WriteJsonReportAtomic`; the JSONL with the same temp-file-then-move semantics. Response mirrors compile_all: `{out_path, index_path (absolute), totals:{total, exported, failed, not_found, skipped, excluded_by_type}, by_type, first_failures (≤10)}`.

### D3 reflect.export_dependency_graph
Params `path_prefixes:array[string]` (required), `edge_kinds:array[string]` (default all), `ordering_kinds:array[string]` (default hard kinds, see below), `out_path` (required, same policy). CortexReflect gains private deps `UMG` (widget trees) only; no dependency on CortexBlueprint/CortexGraph.
Edge derivation (from → to, "from depends on to"):
- `inherits`: ParentClassPath tag (no load).
- `implements`: loaded BP `ImplementedInterfaces`.
- `calls_message`: `UK2Node_Message` → interface class of the called function, and `UK2Node_CallFunction` whose function reference's member parent is an interface class (typed interface calls).
- `casts`: `UK2Node_DynamicCast::TargetType`.
- `spawns`: `UK2Node_SpawnActorFromClass` class pin default object.
- `creates_widget`: `UK2Node_ConstructObjectFromClass` nodes whose class is `K2Node_CreateWidget` (by class name) → class to spawn.
- `widget_tree_child`: widget tree widgets whose class is a Blueprint-generated user widget.
- `listview_entry`: widgets with an `EntryWidgetClass` class property set.
- `level_placement`: World assets under prefixes whose Asset Registry hard dependencies include the BP package.
- `struct_use` / `enum_use`: Asset Registry dependencies to UserDefinedStruct / UserDefinedEnum assets.
- `config`: D1 references (from = ini file node).
Targets normalised to asset object paths (generated classes `_C` → BP asset).
Node scope: Blueprints (level-script Blueprints excluded), World, UserDefinedStruct and UserDefinedEnum assets under the prefixes are the scheduled nodes (`kind` blueprint/world/struct/enum). Referenced targets outside the prefixes (including native `/Script/` classes, `kind:"native_class"`, and config targets outside the prefixes) are nodes flagged `external:true`; config targets that are other in-prefix assets are nodes with `kind:"asset"`; ini files are `kind:"config_file"` nodes. External, `asset` and config-file nodes are never scheduled. `level_placement` means "the World asset hard-depends on the Blueprint package" (Asset Registry), not an actor-level placement scan, or, for World Partition / One-File-Per-Actor maps, a hard referencer package of the Blueprint under `/<Root>/__ExternalActors__/<map package path>/...` (`ULevel::GetExternalActorsPath` convention) whose map is a World under the prefixes (longest matching map wins; `ResolveExternalActorWorld`). Edges with `from == to` are dropped at insertion. `path_prefixes` parsing and the Asset Registry enumeration (scan, class filter, level-script drop, case-sensitive object-path sort, per-prefix `matched_assets`) are one shared CortexReflect helper (`CortexReflectAssetEnumeration`) used by this command, `find_name_lookups` and `find_duplicate_graphs`; the file and response carry `matched_assets:{prefix:count}` and a `warnings` entry for every prefix that matched nothing. All new reflect commands are `StrictParams`; `load_failures` is emitted only when non-empty.
Wave order: the dependency graph over scheduled nodes is condensed into strongly connected components (every SCC of size ≥1 is one unit) and each component is placed at its longest-path level (0 when it depends on nothing, else 1 + the deepest dependency). All members of a cycle share one wave, nodes downstream of a cycle land in strictly later waves, and there is no catch-all final wave. `cycles` lists the SCCs of size > 1. Ordering uses only hard kinds by default: `inherits`, `implements`, `struct_use`, `enum_use`, `widget_tree_child`, `listview_entry`. Soft kinds (`calls_message`, `casts`, `spawns`, `creates_widget`, `level_placement`, `config`) are still emitted as edges but order waves only when named in the optional `ordering_kinds:array[string]` (validated against the edge kinds; intersected with `edge_kinds`); the kinds actually used are reported as `ordering_kinds`.
File: `{path_prefixes, edge_kinds, ordering_kinds, unresolved:{parents,interfaces}, nodes, edges:[{from,to,kind,graph?,widget?}], waves, cycles}` (+`load_failures`). Response: `{out_path, nodes, edges_by_kind, waves:[sizes], cycles:<count>, ordering_kinds, unresolved}`. `unresolved` counts Blueprints with an unresolvable parent class and interface entries without a class instead of silently dropping them.

### D4 core.batch_query pagination (Python)
`limit`/`cursor` accepted by the batch_query facade: the batch executes once, `results` are stored in the pagination cache, pages are served from cache (never re-executing). Without `limit`, a response that fits is returned whole. An oversized one never discards the executed results and never advises re-running (the steps may mutate): the executed results are stored as a snapshot and the first page that fits is returned with `_pagination` (`next_cursor`, `snapshot_id`) and a `_note` that the batch already executed and the remaining step results are available by `cursor`. The long-synchronous receive window (1800 s) also applies to `blueprint.export_migration_analysis`, `reflect.export_dependency_graph`, `reflect.find_duplicate_graphs` and `reflect.find_name_lookups`.

### D5 Pagination snapshot/TTL (Python)
`PaginationCache(max_entries=16, ttl_seconds=600)`; each store gets a monotonically increasing `snapshot_id` included in the cursor and `_pagination`; identical requests no longer overwrite each other's snapshot (key = request hash + snapshot_id).

### D6 reflect.find_name_lookups
Params `path_prefixes:array[string]` (Blueprints to match against), `symbols:array[string]` optional filter. C++: scan `.h/.cpp` under `FPaths::GameSourceDir()` and project plugins' `Source/` (fixed roots, no caller-supplied paths) for string-literal arguments of `FindFunction`, `FindFunctionByName`, `FindFunctionChecked`, `FindPropertyByName`, `FindFProperty`, `SetTimerByFunctionName`, `K2_SetTimer`, `CreateUFunction`, `BindUFunction` (literal forms `TEXT("X")`, `"X"`, `FName("X")`, `FName(TEXT("X"))`). Blueprint: `UK2Node_CallFunction` calling `K2_SetTimer`/`K2_SetTimerForNextTick`/`SetTimerByFunctionName`-style functions with a literal `FunctionName` pin. Each hit `{source:"cpp"|"blueprint", file|asset_path, line|node_id, api, name, matches:[{asset_path, member, member_kind}]}` where matches are BP functions/events/variables/custom events with that name under the prefixes. Plugin's own source is excluded.

Result additionally carries `scanned_files` (source files actually read), `unreadable_files`, `matched_assets`/`warnings`. Optional `out_path` (`FCortexSafeFileContract::ResolveWritePath`, refused before any work): the full result goes to the file and the response is a compact summary (all scalar fields plus the first 10 `cpp`, `blueprint`, `matched_names`, `unmatched_names` entries and a `<name>_total` count for each). Without `out_path` behaviour is unchanged and Python's refusal suggestion names `out_path`. The GC after the run only releases objects the loaded Blueprints no longer reference (`RF_Standalone` keeps the Blueprints loaded).

### D7 reflect.find_duplicate_graphs
Params `path_prefixes` (required), `min_nodes:int=5`, `similarity:number=0.9`. Per function/macro/ubergraph event-chain graph: normalised hash over canonical node descriptors (class, member reference, non-default pin values, link topology by descriptor index; excludes GUIDs, positions, comments, knots). Exact groups = identical hash. Similar groups = graphs with the same name in different Blueprints whose node-descriptor multiset Jaccard ≥ `similarity`. Widget trees compared the same way (class+name multiset) as `kind:"widget_tree"`. Response `{exact_groups, similar_groups, blueprint_pairs:[{a,b,shared_graphs,widget_tree_similarity}]}` sorted by size; complete-or-refuse in Python. Exact groups ignore function local variables (types and defaults). Result carries `matched_assets`/`warnings`; optional `out_path` writes the full result to a file and returns a compact summary (counts plus the first 10 `exact_groups`, `similar_groups`, `blueprint_pairs` with `<name>_total`); Python's refusal suggestion names `out_path`.

Loose similarity (live Ripper finding): exact groups stay strict, but similar groups and widget-tree similarity use a loose descriptor where every reference to a Blueprint-generated class other than self (member parents, cast targets, pin type objects, class pin defaults, widget classes) becomes its nearest native ancestor class name and BP member references keep only the member name. Widget-tree similarity is Jaccard over (widget name, native-ancestor class, parent widget name) tuples. Similar groups carry `loose:true`; the size-ratio prefilter and star clustering are unchanged.

## Contracts and synchronisation
New commands declared in handlers; fixture + generated fallback; toolkit `mcp-tool-reference.md`/`reflect-patterns.md` sync. File-writing commands are not on the Blueprint read-only bypass list for mutation guards but perform no asset mutation; they never save assets.

## Slow-model review follow-up (2026-11-05)
An independent post-merge review of PR #192 (merge `1e224991`) reported seven P2 findings; each was confirmed against the source (and the UE 5.8 engine source where cited) and fixed:
- **I1 batch cursor expiry.** `_cursor_expired` told every caller to re-send the original command; for `core.batch_query` that replays mutations. The expiry message is now command-aware: a batch cursor reports that the batch already executed, its results are no longer available, and that it must not be re-sent. Other reads keep the re-send guidance.
- **I2 StrictParams.** The Blueprint handler declared `.StrictParams()` for `export_text_inventory`, `export_snapshot`, `compare_snapshots`, `compile_all` and `export_migration_analysis` but never called `FCortexCommandContract::ValidateDeclaredParams`, so `type` instead of `types` exported everything. `FCortexBPCommandHandler::Execute` now validates against `GetSupportedCommands()` before dispatch (as the Data, UMG and Reflect handlers do).
- **I3 OFPA placement.** `level_placement` was derived per in-prefix Blueprint from its referencers, so a Blueprint outside the prefixes placed by an in-prefix World was missed. It is now derived per World: the packages under `ULevel::GetExternalActorsPath(World)` are enumerated and every Blueprint they hard-depend on becomes a `level_placement` edge (out-of-prefix targets are external nodes, like an ordinary map's dependencies). `ResolveExternalActorWorld` (path mapping) is removed.
- **I4 widget members.** `find_name_lookups` indexed `NewVariables`; Widget Blueprints keep generated properties of variable widgets and widget animations in `UBlueprint::GeneratedVariables` (`WidgetBlueprintCompiler.cpp:1510-1595`). They are indexed as `widget_variable` (and `widget_animation` when the variable type is a `UWidgetAnimation`).
- **I5 strict widget hash.** The strict widget-tree hash used `Widget->GetClass()->GetName()`; it now uses the full class path (self-normalised like function units), so child widget classes of different packages with one short name are no longer exact duplicates. The loose descriptors still use the native ancestor.
- **I6 export pair.** `export_migration_analysis` reads the previous JSONL up front (refusing before any work when it cannot be read), publishes the JSONL and then the index, and on index failure restores the previous JSONL (or removes the new one), so the JSONL beside the index never comes from another run; the error says which recovery happened.
- **I7 config tokenizer.** The package part of a token now ends only at the characters `FPackageName` rejects in a long package name (`\ : * ? " < > | ' , . & ! ~ @ #`, whitespace; `*`/`?` stay for wildcard skipping), so `( ) { } [ ] = ; ^ % $ \`` stay inside; an unbalanced closing bracket still ends an unquoted token (`(Map=/Game/Maps/Arena)`). After the first `.` the object-path delimiters apply as before. Known consequence: `=` and `;` inside an unquoted value are part of a path (a value like `/Game/A;/Game/B` reads as one token).
