## Rejected/retained candidates and rationale

- Schema type versus cpp_type: not redundant. Concrete C++ type and semantic discriminator differ (CortexSerializer.cpp:1848-1912); preserve both, including enum/subtype/array metadata.
- NonDefaultPropertiesToJson on a CDO and whole parent-memory comparison: wrong baseline/unsafe; TE06 uses ownership-checked per-property baseline.
- Omit all zero/false/null/default-looking struct fields by default: loses effective-value semantics and clears; no.
- Strip /Name.Name, shorten keys/IDs globally or TSV all results: canonical targeting and typed/nullable nested values matter; explicit fields and names-only views are sufficient.
- New list/remove tools, generalized response-policy infrastructure across all native domains, schema-id/reference format migration, automatic changed-only cache reads: no present need beyond existing owners.
- Drop graph.describe_node pins/prerequisites/non_retryable_errors, binding orphan records, rollback/residual inventories, mutation outcome or warning/error evidence: invalid optimization.
- Deduplicate context across turns, omit resumed access instructions, or move conversion system policy into user text without provider lifecycle proof: unverified safety/lifecycle change; not admitted.
- Rendering RawJson, token labels and tool blocks do not themselves add model tokens; no visual restyling.
- Asset-chip unresolved implementation and screenshot naming drift are documented incidental findings; no unrelated fixes/remote follow-up tickets in this planning task.
