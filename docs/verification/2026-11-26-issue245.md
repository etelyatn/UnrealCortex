## Acceptance

| Criterion | Evidence | Result |
|---|---|---|
| Decide whether AI-driven PIE disables FPS throttling | Decision: yes, for Cortex-started sessions only. The old `t.MaxFPS 0` / `t.UnfocusedFrameRateLimit 0` injection has no effect on UE 5.8; the cap is `UEditorEngine::GetMaxTickRate` (3 FPS while `ShouldThrottleCPUUsage()`). See the design. | Done |
| Implemented on the live path with a test against the live module | Native CortexEditor change. `Cortex.Editor.PIE.CPUThrottleBypass.CortexStartedSessionOnly` and `Cortex.Editor.PhysicalInputOwnedCPUThrottleBypass` failed RED (3 + 2 "vetoes" assertions: 0 instead of 1) before the change and passed GREEN after it | Pass |
| Human-started PIE keeps the engine default | The same test asserts no veto for an engine-started session. Live: engine-started PIE ran at 3.0 frames/s while minimized | Pass |
| Veto released on every end path | Tests: `stop_pie`, engine end (`RequestEndPlayMap`, as a toolbar stop), owned teardown. Live: idle editor back to 3.0 frames/s after `stop_pie` | Pass |

### Live proof (task-owned editor, `project_name` CortexSandbox, port 8743)

`Saved/Issue245/live_probe.py` minimized every editor window before each sample (foreground process was not the editor) and measured `unreal.SystemLibrary.get_frame_count()` over ~4 s:

| Phase | Frames/s |
|---|---|
| Idle editor, minimized | 3.0 |
| Engine-started PIE (`LevelEditorSubsystem.editor_request_begin_play`) | 3.0 |
| Cortex `editor.start_pie` (`selected_viewport`) | 60.0 |
| Idle editor after `editor.stop_pie` | 3.0 |

## Review

An independent review found no Critical issues. One Minor finding (design wording on the throttle condition) was fixed. Three Important findings were checked against source and declined, with the reasons recorded in the design's "Ownership boundaries" section: a one-frame request replacement that the tracker already adopts as the `start_pie` result; a Ready owned session ended by the engine, which the shipped Replay owners finalize every tick; and unload of the CortexEditor module, which only happens at editor exit.
