## RED / GREEN

RED = production sources at `main`, new tests present (branch candidate snapshotted to
`Saved/Issue274/candidate.patch`, restored byte-identically afterwards).

- Compile-level RED: `CortexEditorUtilityTest`, `CortexGraphMigrationPruneTest`, `CortexBPReparentRecoveryTest`
  reference new APIs (`GetRecentLogs` 8-arg, `bIncludeResultProducers`, `bJournalCdo`). They were set aside for a
  runtime RED build and re-included for GREEN.
- Runtime RED: 39 of 47 compiled new/changed tests ran on `main` and **all failed**; the remaining 8
  (`Cortex.Blueprint.EmbeddedTemplates.*`, `Cortex.Blueprint.Reparent.*` new cases,
  `Cortex.Graph.Authoring.Migration.Prune.*`, `Cortex.Editor.ConsoleCommand.EditorWorld*`,
  `Cortex.Editor.Utility.LogCapture.ContainsFilter`) are the compile-bound ones above.
  `Cortex.Core.Shutdown.RefusesDirty` was excluded from RED on purpose (on `main` its default `force:true` exits
  the test editor). Python RED: 19 failures in `test_editor_lifecycle.py`/`test_response.py`.
- GREEN: `Cortex.Core+` 252 tests (250 pass, 1 pre-existing `level.spawn_actor` count failure — identical on `main`,
  from #266), `Cortex.Graph+` 390/390, `Cortex.Blueprint+` 425/425, `Cortex.Editor+` 202/202, `Cortex.UMG+` 185/185,
  `Cortex.Reflect+` 107/107, `Cortex.QA+` 21/21. Python offline suite 1319 passed.
- Known intermittent: two `Cortex.Blueprint+` runs crashed in `UE::GC::…FlushQueuedReferences` (address 0xc) at
  different tests; the identical crash exists in a pre-branch crash dump (2026-11-17) and a third run was clean
  425/425. Scanner pass over the diff found no dangling-reference mechanism in the new code; the one exact
  mechanism in the tree (`FRemovedNodeEntry::Node`, raw `UEdGraphNode*` journaled by `graph.apply_patch`) predates
  this branch and is not exercised by the Blueprint suite. Reported, not fixed (out of scope).

## Review rounds

Three reviewers (editor/core, graph/blueprint-batch, qa-reflect-umg-reparent) read the candidate; all findings were
source-verified before fixing. Fixed: `/Temp/` dirty packages excluded from shutdown refusal; Simulate-In-Editor
mislabelled as PIE capture; `auto` capture failing when Slate cannot render (broke `qa_test_step`); restart
adopting a rival editor's port file / verifying through rediscovery; `reload_packages` lost after undo; zero/false
values skipped by the CDO journal and template tracking; unity-build name collisions; `parent_call` resolving in a
shared event graph; set-rollback stopping before reattaching collapsed graph hosts; `get_subgraph` summary
reporting `edge_count` without an edges array; `remove_graph` set failing with a macro instance in the same event
graph; preview/apply mismatch for BlueprintCallable overrides. Rulings: the restart "editor exits right after a
successful probe" race is not closable by polling and is declined; the reparent CDO journal deliberately excludes
the Blueprint's own variables and strong object refs (such runs fail closed through the snapshot check, documented).

## Limits

- `dirty_packages[].file` is absolute (fixed after the live check showed a climbing relative path).
- Embedded resync compares/copies typed property values; instanced subobjects and delegates are excluded, and the
  report filter matches the diff command's (editable properties declared below `UUserWidget`).
- The offline capabilities fixture (`capabilities_cache_full.json`) is already stale for unrelated domains
  (anim/level, #245/#266) and is not regenerated here; `core_cmd`/`editor_cmd`/`graph_cmd`/`umg_cmd` route the new
  commands live.
- Not exercised live: `umg.get_embedded_widget_diff` on a Blueprint that really embeds a widget (no such asset in
  the sandbox), and the restart refusals for a hidden/minimized Slate window.
