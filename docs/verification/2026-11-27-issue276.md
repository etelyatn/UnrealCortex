## Rulings

- **Timed input became non-blocking.** The issue expects `injecting: true` while the action is held. A blocking reply
  could not show the held state, and it outlived the 30 s deferred window. No plugin, toolkit or Replay consumer
  depended on the deferred reply (design-review check).
- **Review finding 12 was not adopted.** The finding asked new PIE tests to skip when PIE is already active. Every
  existing PIE automation fixture uses the same unguarded start/end pattern, and `RunTests.ps1` starts without PIE.
- **The `UMGAnimationBindingTestUtils` fixture now marks its Widget Blueprint garbage.** It previously left a dirty
  transient Widget Blueprint behind. The first PIE start in the UMG suite then recompiled it and hit an engine
  ensure (`WidgetBlueprintCompiler.cpp:792`).

## Known limits

- If raw-stats mode starts while a capture is already running, the capture ends in `TIMEOUT`. Raw mode that is
  already active is refused.
- `set_pie_cursor` has one undetectable case: the cursor is latched, then the controller hides its cursor while the
  viewport stays captured. That state cannot be told apart from default hidden-cursor PIE through public API.
- Object arguments to `broadcast_delegate` take object paths.
- `capture_screenshot` resolves a relative `output_path` against the engine binaries directory (observed during
  triage). This is outside #276; it is reported, not changed.
