Issue: https://github.com/etelyatn/UnrealCortex/issues/229. Environment: Windows, UE 5.8 (installed engine), CortexSandbox, `UnrealEditor-Cmd` automation via `cli/Testing/RunTests.ps1` (`-NullRHI`). Base `0fd57b97` (0.4.15).

## Independent review

A read-only reviewer found that without a declared owner the `graph.apply_patch` readback compared only the member name, so a self-context getter satisfied a replay that asked for `context: "external"`. Confirmed by a RED test and corrected: the reference form is part of the identity with or without an owner. Re-review of the correction found no defects.

## Limits

Verified through the native command router in automation; no MCP-over-TCP session against a live editor was run. The reporter's own AnimBP was not available; the native test parent reproduces its shape and messages.
