# Issue 226 verification: honest writes, bounded reads, canonical codes, one MCP failure shape

Issue: https://github.com/etelyatn/UnrealCortex/issues/226 (reported by @XpycT). Environment: Windows, UE 5.8, MSVC `CortexSandboxEditor Win64 Development`, Python MCP server with mcp 1.26.

The work was developed on base `606bf439` (0.4.14). Before publication it was rebased onto `0fd57b97` (0.4.15, issue 227). That upstream change touched only `MCP/`, so the native sources are identical before and after the rebase. The full rows below were run on rebased head `f9b90149`.

The branch was then rebased onto `f305ab82` (0.4.16, issue 229). That change touched CortexGraph (`CortexGraphPatchOps.cpp`, `CortexGraphSymbolResolver`, `CortexGraphNodeContract.cpp`). On the final tree the build had 0 warnings, `Cortex.Graph+` passed 368/368 (including the issue 229 tests) and `Cortex.Blueprint+` 402/402, and the Clang gate passed for `CortexGraphPatchOps.cpp` and `CortexGraphNodeOps.cpp`. No other native source changed.
