| Run | Filter | Result |
|---|---|---|
| RED (tests only, production unchanged) | `Cortex.UMG.TreeIntegrity+` | 0/5 passed. Reparent of the root under `Box` succeeded (cycle). Review correction: the first candidate refused every name still outered to the tree. An undone `add_widget` keeps its object for redo, so re-adding the same widget was refused, which is a regression. The guard now refuses only a different-class occupant (the `StaticAllocateObject` fatal case). `UndoRestores` covers undo-then-recreate.
