## Independent review

A read-only reviewer found two issues in the first candidate; both were confirmed by RED tests and corrected:

1. `switch_editor` mutated the connection without `_socket_lock`, which now matters because tools run concurrently. It now calls `UEConnection.retarget`, which holds the lock.
2. `timeout_s` called `math.isfinite` on integers, so a huge JSON integer overflowed. Now only floats are checked, and the value is clamped before conversion.

Re-review of the correction found that a retarget during the reconnect delay could still redirect the retry. A retarget generation now stops the retry.

## Found, not changed

The deleted `MCP/tools/editor/composites.py` held `_inject_fps_throttle`, which was merged into that dead copy only (`a8062fc8`) and never reached the live `start_pie_session`. Its single test was removed with the copy.
