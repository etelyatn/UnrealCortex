## Behavior changes

| Change | Proof |
|---|---|
| `blueprint.get_info` `include_inherited` default false | `Cortex.Blueprint.GetInfo.InheritedDefaultFalse` |
| `source` on every entry when inherited listed (compact incl.) | `GetInfo.CompactSourceWhenInherited`, updated `GetInfoCompact` |
| Compact pins omit `category`, empty `subcategory`/`sub_category_object`, `container_type:none`, false flags | Extended `Cortex.Graph.CompactSerialization` (compact absent, verbose present) |
| `level.get_bounds` always emits `scan_truncated` | `Cortex.Level.Query.GetBounds.ScanTruncated` |
| Non-paging overflow hints name narrowing, not `limit` | `test_truthful_overflow_hints.py` |
| `graph.trace_*` / flat hierarchy oversized refuse naming `max_depth` / `max_results` | `TestSelectorPolicyEntries` |
| No-limit `CACHED_PAGE_ARRAYS` overflow returns page 1 + `next_cursor`, single dispatch, contiguous continuation | `test_no_limit_first_page.py` |
| Six reflect wrappers gone; presets keep the five non-duplicates | `test_tool_listing_contract.py`, `test_capabilities.py` |
