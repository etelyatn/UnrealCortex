## Implemented contract

`CortexST::CollectAllStates(Context, OutStates, bIncludeSelectorFields=true)` is the shared all-root owner; `CollectStates` remains the single-root entry. Stored subtree/child order is preserved with one visited set across roots, seeded from existing output. Null/repeated references are skipped and child cycles terminate, preserving first ownership/order without rewriting native Parent/Children. Normal dump/read/state/transition selectors share the addressable state set, default to the first valid root, and retain path ambiguity and destructive root restrictions. Stored inspection passes false to omit selector metadata and avoid off-page string work or malformed Parent-chain walks; ordinary selector APIs are not claimed safe for malformed Parent cycles.

`dump_tree` keeps the existing `statetree_cmd` tool and opt-in `inspect_instances`. True alone returns unpaged stored inspection. A named section (`root`, `states`, `nodes`, `bindings`) enables paging; default offset0/count1, count1..100, offset0..INT32_MAX. Present fields are strictly typed, finite integral JSON numbers where required; disabled/missing-section paging and malformed values return `INVALID_FIELD` before reflection. Offset==total returns empty terminal metadata; offset>total fails. Native references/descriptors are enumerated/countable before selected bodies are serialized. Pages preserve schema/provenance/completeness, native node/owner identity, total/offset/returned_count/has_more, and before/after package dirtiness.

Root includes editor metadata/root parameters and null-preserving subtree slots. States omit separately paged node bodies; nodes include state tasks/single-task/conditions/considerations/transition conditions plus evaluators/global tasks; bindings are actual stored property-path records. Stored values never execute nodes, compile, save or substitute class defaults. Local compound traversal preserves nested fixed arrays/containers/optionals and appends branch-owned diagnostics, so dotted/bracketed map keys cannot erase siblings. Core leaf policies remain unchanged. Actual uint32 values (fixture4000000001) are exact; signed int64 beyond ±9007199254740991 are decimal strings with original cpp_type, while safe values remain numbers. Reflected GUID int32 signs preserve native bit identity; unsigned display/case is not an identity contract. Unsupported/depth-limited values, identity-only references and set-order issues remain honest.
